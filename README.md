# awesome-free-dev-tools
> Free developer tools, no credit card. Curated, simple, and free to use — one line per entry.
- [Hoppscotch](https://hoppscotch.io/) — Open-source API testing in the browser
- [Postman](https://www.postman.com/) — API platform with a free plan
- [DevToys](https://devtoys.app/) — JSON, encoding, hashing and more in one app
- [Carbon](https://carbon.now.sh/) — Beautiful screenshots of your code
- [Excalidraw](https://excalidraw.com/) — Diagrams developers actually enjoy making
- [Supabase](https://supabase.com/) — Free Postgres and auth
- [Cloudflare](https://www.cloudflare.com/) — DNS, CDN and Workers on a free plan
