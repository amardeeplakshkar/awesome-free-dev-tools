## API and Testing
| Tool | What it does |
| --- | --- |
| [Hoppscotch](https://hoppscotch.io/) | Open-source API testing in the browser |
| [Postman](https://www.postman.com/) | API platform with a free plan |
| [Bruno](https://www.usebruno.com/) | Open-source API client, Git-friendly collections |
| [Insomnia](https://insomnia.rest/) | API client for REST, GraphQL, gRPC |
| [JSONPlaceholder](https://jsonplaceholder.typicode.com/) | Free fake REST API for testing |
| [Swagger Editor](https://editor.swagger.io/) | Design and validate OpenAPI specs |
